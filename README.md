**为什么有两套模拟期。** 初稿用 30 日，每次重复的期望事件数仅约 1.5 起，事件率估计对随机种子敏感。
投稿版把模拟期延长到 180 日、重复 100 次，并在**同一组随机任务流**上对情景做配对比较
（同一 seed 对应同一批任务），因此给出的是配对差值而非独立样本均值。

## 模型要点（与 `sim_core.py` 逐项对应）

### 1　任务流

每日任务数 $n_d\sim\mathrm{Poisson}(1500\,\delta)$；任务按需求权重 $w_k=d_k/\sum_k d_k$ 落入
6 个辖区（首都核心、枢纽群、市场化、山地、边海、低密度）；风险等级按低∶中∶高 $=0.6:0.3:0.1$；
18% 的任务跨辖区，目的辖区在其余 5 个中均匀抽取。

### 2　申请与排队

需申请概率由情景给定：$P(\text{需申请}\mid r_i)=\rho_{r_i}$，$\rho=(\rho_L,\rho_M,\rho_H)$。
未建立互认时，跨区任务须在目的辖区**重复申请**。辖区 $k$ 内第 $j$ 个排队任务的等待时延为

$$w_{j,k}=\frac{j}{\mu_k}\cdot 24\ \text{(h)}$$

超过容忍度 $\tau=12$ h 的任务中 $p_{\text{unauth}}=0.60$ 强行飞行（构成违规），其余取消。

### 3　事件概率（核心公式）

$$p_{\text{inc},i}=p_0\,m(r_i)\,(0.6+0.8d_{k})\,(1-0.6c_{k})\,(1+3u_i)\,(1+0.7\max(0,\rho_{k}-\rho_0))\,\varphi(r_i)$$

| 符号 | 含义 | 取值 |
|---|---|---|
| $p_0$ | 基准事件率 | $3\times10^{-5}$ |
| $m(r)$ | 风险倍数 | $(1,\,3,\,10)$ |
| $d_k$ | 辖区需求/地面暴露密度 | $(0.35,0.95,1.00,0.60,0.45,0.20)$ |
| $c_k$ | 辖区治理能力（感知+处置） | 基准 $(0.70,0.65,0.75,0.45,0.50,0.30)$ |
| $u_i$ | 违规飞行指示 | $\{0,1\}$ |
| $\rho_k$ | 空域负载 | $n_k/(250+900d_k)$，阈值 $\rho_0=0.8$ |
| $\varphi(r)$ | 分层保护因子（仅分类治理生效） | $\varphi_H=1-0.45\varepsilon_k$，$\varphi_M=1-0.20\varepsilon_k$，$\varphi_L=1$；$\varepsilon_k=\min\{1.2,\;c_k/0.75\}$ |

事件还须**未被检出**：违规飞行被发现的概率为 $0.55c_k$，检出则该次不计入事件。

### 4　成本

$$C=\sum_{\text{hit}}\mathrm{sev}(r_i)+300\,N_{\text{cas}}+0.02\,N_{\text{app}}+0.003\!\sum_{\text{served}}\!w_i+0.5\,N_{\text{det}}+0.15\,N_{\text{int}}$$

$\mathrm{sev}=(20,50,120)$ 万元/起；伤亡附加 300 万元/起；后四项依次为行政、等待、查处、中断成本。

### 5　指标定义

| 指标 | 定义 |
|---|---|
| 事件率（起/万架次） | $E=10^{4}N_{\text{hit}}/N_{\text{fl}}$ |
| 完成率 | $C=N_{\text{comp}}/N$（飞行且未被中断） |
| 违规率 | $U=N_{\text{unauth}}/N$ |
| 重复申请（次/项） | $R=N_{\text{dup}}/N_{\text{cross}}$ |
| 单位治理成本（万元/千架次） | $G=10^{3}C_{\text{total}}/N$ |

### 6　空间集中度实验（图 2）

在**保持平均暴露不变**的前提下改变分布：

$$d_k(\kappa)=\frac{D_k^{\kappa}}{\overline{D^{\kappa}}}\cdot\overline{D},\qquad
\mathrm{CV}=\frac{\sigma(d)}{\mu(d)}$$

$\kappa=0$ 为完全均匀，$\kappa=1$ 还原基准分布，$\kappa$ 越大越集中。每个 $\kappa$ 用同一随机种子
配对运行 S2+（扩容+等量投入）与 S3（分类治理）。
注意 $d_k$ 同时出现在暴露项与空域容量项 $250+900d_k$ 中，因此集中度上升会同时抬高两类情景的事件率；
图 2 报告的是**两者之差**，不是任一情景的绝对水平。

### 7　风险校准（命题 3）

Poisson–Gamma 共轭更新。类别 $c$ 的先验 $a_c=\theta^{(0)}_c s,\;b_c=s$（$s=15$）；
$y_c\sim\mathrm{Poisson}(\lambda_c)$，$\lambda_c=b_0m_cn_c$；仅以覆盖率 $\pi$ 抽样观测
$\mathrm{obs}_c\sim\mathrm{Binomial}(y_c,\pi)$。每期回写：

$$a_c\leftarrow a_c+\mathrm{obs}_c,\qquad b_c\leftarrow b_c+n_cb_0\pi,\qquad \hat\theta_c=a_c/b_c$$

误差 $\mathrm{MAE}_t=\frac{1}{3}\sum_c|\hat\theta_{c,t}-m_c|/m_c$。
「仅监测不回写」（L1）与「不监测」（L0）在实现上走同一分支，故两者**逐点完全相同**——
这不是巧合，是论文命题 3 的形式内容。

### 8　解构实验：把改进拆成"排序"与"保护"（`journal_ablation.py`）

固定 S3 的资源水平，只切换两个开关——是否按风险优先排队（P）与是否启用分层保护 φ（M）：

| 单元 | 事件率（起/万架次） |
|---|---|
| 不排序不保护 | 0.473 |
| 仅排序 | 0.473 |
| 仅保护 | 0.361 |
| 排序 + 保护（= S3） | 0.361 |

**排序贡献 0.000（95% CI 0.000—0.000），保护贡献 −0.112（−0.122—-0.102）：基准设定下改进全部来自分层保护强度。**
原因是 S3 的需申请比例约 25%、审批队列从不溢出（违规率为 0），排序机制没有被激活。

把审批容量自上而下收紧，排序收益才出现：

| 审批容量倍数 | 有排序 | 无排序 | 排序收益 |
|---|---|---|---|
| 1.4 | 0.471 | 0.471 | 0.0% |
| 0.7 | 0.451 | 0.459 | −1.7% |
| 0.5 | 0.478 | 0.496 | −3.7% |
| 0.35 | 0.550 | 0.586 | −6.1% |
| 0.25 | 0.531 | 0.597 | **−11.1%** |

保护强度敏感性：令 φ 的折减上限同乘系数 s，s = 0/0.25/0.5/0.75/1 时，相对"不排序不保护"的降幅为
0.0/−5.8/−12.0/−18.0/−23.7%（近似线性）。审批容量倍数 1.0—1.8 与等待容忍 6—24 h 的扫描见
`results/ablation_capacity.csv`、`results/ablation_tau.csv`，S3 相对 S2+ 的降幅分别为 24.6%—26.4% 与 25.9%—26.9%。

```bash
python journal_ablation.py   # -> results/ablation_*.{csv,json}
```

> 结论：**在本模型设定下，"把有限能力优先配置给高后果任务"的收益不是恒定的，而是审批容量约束的函数；
> 容量充裕时为零，容量收紧至约 1/4 时达 11.1%。** 论文正文按此改写。

## 参数校准接口

四个观测量与四个参数一一对应：平均审批时延 → 审批容量倍数；违规率 → 超时强飞比例；
每万架次事件率 → 基准事件率；跨区交接中断率 → 交接中断概率。
`calibration.py` 用矩匹配逐个二分求解，两轮迭代。

回测：以一组留出参数（容量 0.90、强飞 0.55、基准事件率 $4\times10^{-5}$、中断 0.12）生成观测值，
再反推参数，误差分别为 0.6%、4.3%、7.5%、1.5%；模拟值与观测值的相对偏差均在 8% 以内。

## 局限

- 无公开来源而取设定值的参数：审批容量 $\mu_k$、等待容忍度 $\tau$、强飞比例 $p_{\text{unauth}}$、
  空域容量系数 $250+900d_k$、检出概率系数 $0.55$。前三项在 `results/sensitivity.csv` 中变动。
- 模型未纳入载人运行、恶意攻击、军地协调、跨境飞行；未建模运营主体之间的策略互动与学习。
- 情景之间的**相对差异**与配对差值的置信区间有意义；事件率的**绝对水平**没有意义。
